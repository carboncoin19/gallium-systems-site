Product line

Two devices. One connected system.

Every device joins the same local cluster and speaks the same app and cloud layer — install one or install a whole property.

⏻

Smart Switch

A drop-in relay switch for lighting, pumps, and small appliances. Keeps working from the physical button even if Wi-Fi is down.

  • Instant local control, no cloud round-trip required
  • Physical button always in sync with the app
  • Remembers its last state through power loss
  • Joins automations, groups, and scenes
⛩

Auto Gate Controller

Purpose-built gate and driveway control with presence sensing and jam protection, so automation never compromises on safety.

  • Radar-based human-presence safety guard
  • Partial-open, auto-close, and position feedback
  • Motor jam & overcurrent detection
  • Keypad, app, and cloud control in one device
